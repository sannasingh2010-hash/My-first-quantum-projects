# My-first-quantum-projects
This single Python script explores the foundational building blocks of Quantum Machine Learning using the IBM Qiskit framework. 
What This Code Demonstrates:
Part 1: Superposition: Using a Hadamard Gate (`h`) to put a qubit into a 50/50 fluid state.
Part 2: Data Encoding: Using an `ry` rotation gate and `math.acos` to translate a classical percentage into a precise geometric quantum angle.
Part 3: Quantum Logic: Utilizing a CNOT gate (`cx`) to build a conditional "Sensor and Alarm" system where one qubit controls another.
Part 4: Quantum Neural Network (QNN): Combining a raw data input angle and an AI weight angle on a single qubit to generate a classification prediction.
